# Источники и сторонние компоненты

- Windows-пакет включает официальный Node.js 24.16.0 с исходной лицензией `runtime/NODE-LICENSE.txt`, а также Wrangler/Miniflare/workerd и их зависимости с лицензиями внутри пакетов. Лицензии библиотек, вошедших в готовые JS-файлы (включая React, ReactDOM и Lucide), дополнительно находятся в `licenses/`. Сборка не включает SDK или тайлы Яндекса для офлайн-раздачи.

- Яндекс Карты JS API 3: опционально загружается с официального сервера только после выбора поставщика и наличия ключа владельца. Применяются условия Яндекса; копирайты не скрываются. SDK/тайлы не копируются в архив для офлайн-распространения. Подключение и официальные ссылки — MAPS.md.

- Natural Earth: география стран и Каспия, public domain. https://www.naturalearthdata.com/about/terms-of-use/ ; исходные наборы https://github.com/nvkelso/natural-earth-vector . В приложение включён только отобранный GeoJSON для схемы, не навигационные данные.
- Open-Meteo: внешний прогноз, атрибуция Open-Meteo.com, CC BY4.0; публичный API предназначен для заявленных поставщиком условий некоммерческого использования. https://open-meteo.com/en/docs ; https://open-meteo.com/en/terms . Коммерческая эксплуатация требует отдельной проверки условий.
- DESNZ2025: UK Government GHG Conversion Factors, официальные таблицы по Open Government Licence. Конкретный XLSX и строки указаны в research/AUDIT.md. Коэффициенты не являются сертификацией нашего расчёта.
- Lucide React: векторные иконки, ISC License; пакет и лицензия фиксированы в package-lock.json/node_modules/lucide-react/LICENSE.
- React/ReactDOM, Vite, Vinext, TypeScript, Drizzle, Zod, Tailwind и компоненты стартового шаблона: версии зафиксированы в app/package-lock.json; оригинальные LICENSE пакетов сохраняются при установке. Лицензии исходных компонентов шаблона: `app/scripts/vite/local-preview.LICENSE` и `app/vendor/shadcn-tailwind-4.13.0.LICENSE.md`.
- Happy DOM, tsx и Prettier — инструменты разработки/проверки, не источники операционных данных. Лицензии находятся в соответствующих npm-пакетах.

Чужие логотипы, интерфейсные скриншоты, закрытый код и коммерческие данные в продукт не копировались. Названия платформ и ссылки в исследовании обозначают изученные публичные источники, не партнёрство и не действующие интеграции.
